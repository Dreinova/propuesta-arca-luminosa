# Propuesta Arca Luminosa

Propuesta de rediseño del sitio web de **Arca Luminosa**, fundación de rescate de perros y gatos callejeros en Bogotá, Colombia.

Sitio estático (HTML + CSS + JS, sin frameworks) con animaciones [GSAP](https://gsap.com/), construido a partir del contenido real de la fundación.

## Ver la propuesta

👉 **[dreinova.github.io/propuesta-arca-luminosa](https://dreinova.github.io/propuesta-arca-luminosa/)**

## Estructura

- `index.html` y demás páginas (`adoptar.html`, `dona.html`, `voluntarios.html`, etc.) — el sitio.
- `design-system.html` — sistema de diseño: colores, tipografía, componentes y convenciones de animación usados en todo el sitio.
- `css/` — tokens, base y componentes compartidos.
- `js/main.js` — animaciones e interacciones (GSAP + ScrollTrigger).
- `assets/` — imágenes y logo.
